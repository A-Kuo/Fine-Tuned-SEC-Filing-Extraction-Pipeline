FinDocAnalyzer Debug Console

Human-interface debugging for the FastAPI backend (serving/api.py). Not a production UI.

Backend connection


  


  

    
    
    
    
  


  

    
POST /extract

    
Runs the fine-tuned extraction pipeline over raw filing text. Requires the backend to have a loaded model (or vLLM backend) -- without one it degrades gracefully rather than 500ing, see the response's status/error fields.

    
    
    
    
    
    
    
    

  


  

    
POST /rag/query

    
Lightweight RAG demo over indexed filing sections (src/rag/). Requires config.yaml's rag.enabled: true and a built index -- see scripts/build_rag_index.py.

    
    
    
    
    
    

  


  

    
GET /stats

    
Live request/latency counters from the running server instance.

    
    

  


  

    
GET /pipeline/status

    
Extraction counts and downstream-service health (ticker-agent/viz-framework circuit breakers).
